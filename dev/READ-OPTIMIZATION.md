# Firestore 화면 조회 축소 (2026-11-10)

- 관리자 감시판: 기본 로그 300건 + 예약 300건 + 차단 사용자 목록. 기존 각각 1,500건 조회는 명시적 추가 조회 버튼으로 유지한다. 분석·CSV는 조회된 표본만 사용하며 화면에 범위와 누락 가능성을 표시한다. 전체 사용량의 감소율을 보장하지 않는다.
- 같은 화면의 동시 감시판 요청은 진행 중 요청 하나를 공유한다. 완료 후 새로고침은 새 요청이다. 자동 주기 갱신은 기존에도 꺼져 있었다.
- 내 예약: 동일 UID·전화번호·이름의 동시 요청만 공유한다. UID/ownerId 및 구형 전화번호 매칭, 전체 과거 내역·통계는 유지한다. 완료·실패 후 결과를 보관하지 않아 다음 조회는 새 요청이다.
- 달력: 기존 15분 성공 캐시는 유지하고 같은 범위의 진행 중 조회만 공유한다. 실패는 캐시하지 않는다. 캐시 무효화 시 진행 중 응답도 무효화하며 다른 회원·센터 화면에 늦은 표시를 하지 않는다.
- 예약 확정 트랜잭션, 충돌 검사, 일일 제한, 요금, 결제, 환불, Auth 사용자 상태 구독은 변경하지 않는다. Firebase 설정·인덱스·문서 형식 변경도 없다.

검증: `npm test`, `npm run test:release`, `npm run test:transfer`.
가상 회원·예약과 demo Emulator에서 검증하며 운영 예약·결제·발송을 실행하지 않는다.
실제 사용량 변화는 배포 후 Firebase 사용량에서 비교해야 한다. 활성 사용자 수와 관리자 이용량에 따라 달라진다. 이 변경은 결제 계정 중단이나 할당량 제한 자체를 해제하지 않는다.
